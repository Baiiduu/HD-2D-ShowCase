# 细雨天气与环境音

当前播放 `rain.wav`：轻柔绵延的远处细雨底声，弱化单颗雨滴与高频刺激，让雨声退到游戏背景。源素材 `rain_source.mp3` 来自 Meowa Sound Effects，任务 `job_858f7983347346b498e4a9ca90457ebf`，于 2026-10-10 生成；保留原始文件。

生成后做了高频柔化、雨滴响度压缩和循环接缝处理，成品为 10 秒循环。处理参数和文件校验值保存在 `rain-processing.json`。旧版 `rain.mp3` 保留，任务 `job_0159da1a7a9e4491bf3f3a2f8feb4344`，可在 Rain Sound 中重新选择。

主场景 **Weather → 雨声音效**：

- **Rain Audio Enabled**：雨声开关。
- **Rain Sound**：音频资源，可以替换。MP3、Ogg、WAV 会自动启用循环；不修改源资源的循环属性。
- **Rain Volume Db**：满雨量时音量，默认 −8 dB。0 为素材原始音量，负数更轻。当前场景雨量 0.7 时实际播放约 −9.55 dB；可以继续向下调，例如 −12 dB。
- **Rain Audio Fade Time**：音量过渡速度，以从静音到满雨量的时间为基准。当前场景配置为 3 秒；新节点脚本默认 1.5 秒。切到晴天或关闭雨声时自然淡出。
- **Rain Audio Bus**：播放总线，默认 Master。不存在的总线使用 Master。

雨声只在运行游戏时播放，编辑器预览不播放。音量跟随 Rain Intensity；晴天仍可有花草风摆，但雨声会停止。

本地配置按 Ctrl+S 保存，Remote 中的运行时调整只影响本次运行。

新增 BGM 位于主场景 `BGM` 节点；轻风参数在 `Weather → 轻微风声`。参见 [音乐与轻风配置说明](../audio/README.md)。

完整提示词及真实调用见 [HD 2D Meowa 调用记录](https://chatgpt.com/space/page_a1d8b19baf7c8191913c59c3b647e390) 的“7 制作轻柔细雨环境音”；旧版记录在“6 制作细雨环境音”。

素材检查：处理后 20 毫秒窗口的响度范围从原始新素材约 −54～−21 dBFS 收敛到约 −36～−29 dBFS；没有削波样本或静音断层。此处数值衡量响度平稳程度，最终听感以游戏试听为准。

Godot 实机验证：连续循环超过两轮，雨量对应的实际播放增益约 −9.55 dB；5 秒淡出、停雨停止、重新下雨恢复以及音量即时调整均通过。关闭雨声音效时视觉雨水继续显示。

[当前游戏音量试听](../../../../../docs/weather-preview/rain-soft.wav) 是实际运行的稳定雨声录音，音量已包含当前雨量和播放增益，不是原始素材的满音量试听。

## 镜头水滴

`Weather → 镜头水滴` 控制透明水滴的出现、滑落和淡出。每滴有独立的宽高、倾角、下侧鼓起与平滑不规则轮廓，形状在滑落期间保持稳定。滴内通过厚度梯度折射画面，已有灯光、光晕、倒影和阴影也会随之变形；亮斑取自画面中的光源颜色。人物附近保持清晰。仅在 F5 游戏画面中显示，3D 编辑视口不显示镜头水滴。

- **Lens Drop Size**：最小/最大半径，默认 18～34 像素，以 900 像素高画面为基准。
- **Lens Rim Strength**：轮廓高光强度，默认 0.18；越高越容易辨认水滴。
- **Lens Irregularity**：轮廓与内部厚度的不规则程度，0～1，默认 0.7；0 更圆润，1 变化最明显。
- **Lens Refraction**：厚度梯度产生的最大画面偏移，0～24，默认 9，以 900 像素高画面下的像素为基准。增大后滴内景物与光晕变形更明显；0 关闭折射。
- **Lens Blur**：仅滴内的小范围模糊，默认 1；较低的值更容易看清折射后的景物。
- **Lens Light Response**：从滴下画面亮部产生的局部亮斑强度，0～2，默认 0.55；0 撤下额外亮斑，画面折射仍由 Lens Refraction 控制。
- **Lens Drop Rate / Lens Drop Lifetime / Lens Fade Time**：生成频率、存续时间、消失前淡出时间。

这些参数不改变 Camera3D 的景深。镜头水滴对光影的影响发生在最终画面中，使用已有场景颜色与光晕，不重算世界中的光照或阴影投射。

验证：原生 Godot 实机的独立图案检查中，关闭模糊和轮廓高光后，仍有 3852 个像素因折射改变；灯光响应改变 377 个亮部像素，暗处水滴没有额外发光。8 滴随机形状滑落后保持稳定，人物保护区改变 0 像素，水滴消失后画面与基准逐像素相同。

[镜头折射预览](../../../../../docs/weather-preview/lens-optics.gif) 使用当前相机配置，把测试水滴放在窗灯与霓虹附近以展示折射、灯光响应和消失过程；这些测试落点没有保存到场景。

## 水面与地表反馈

主场景 Weather 的 **Terrain** 引用连接 `World/Ground`。细雨会同时影响水面小涟漪、地面溅点和额外湿润程度；这些效果可以在 3D 编辑视口预览。

| 分组 | 配置 | 含义 |
| --- | --- | --- |
| 水面雨纹 | Water Rain Enabled | 水面反馈独立开关 |
| 水面雨纹 | Water Ripple Density | 满雨量时每平方米每秒的近似涟漪数，0～10；位置和时间有随机变化 |
| 水面雨纹 | Water Ripple Size / Strength / Lifetime | 最大半径（米）、可见强度、扩散消失时间（秒） |
| 地表雨水 | Ground Rain Enabled | 地面溅点与天气湿润反馈开关 |
| 地表雨水 | Ground Splash Density / Size / Strength | 溅点数量、最大半径（米）和强度；硬质地面更明显，草地更轻 |
| 地表雨水 | Rain Wetness | 叠加在 ArtDirection 原有 Wetness 上的额外湿润程度，0 可关闭湿润变化 |
| 地表雨水 | Wetting Time / Drying Time | 按满雨量额外湿润量计算的打湿/恢复时间（秒） |

停雨后不再生成雨水反馈，地表额外湿润会逐渐恢复；关闭天气总开关或关闭 Ground Rain Enabled 则撤下额外湿润。原有地表材质、水流、倒影、灯光和 ArtDirection 的 Wetness 配置继续生效。

涟漪密度和尺寸同时调得很高时，密度会受完整圆环采样范围限制。建议先调强度，再调数量与尺寸。

验证：实机检查了水面/地面的独立开关、密度即时更新、停雨后恢复，以及镜头水滴淡出无残留；镜头水滴测试中人物保护区域的像素没有变化。14 个新增 Inspector 字段和编辑器预览开关、动画时钟、材质更新均通过检查。
