# Meowa 地编素材 · 第一批

共 18 个独立透明 PNG，分为花、草、小石子，每类 6 个变种。适配当前四境 Godot 项目的像素人物与低俯角 HD-2D 画面。

| 类别 | 文件 | 变种内容 | 可见像素尺寸 |
| --- | --- | --- | --- |
| 花 | `flowers/flower_01.png` ～ `flower_06.png` | 白色矮花、粉色矮花、淡紫矮花、黄色细茎花、蓝色双朵花、红花与花苞 | 矮花 20×16 ～ 20×20；细茎花 26×33 ～ 29×33 |
| 草 | `grass/grass_01.png` ～ `grass_06.png` | 低矮疏草、展开密草、细长草叶、羽叶杂草、双茎阔叶草、金黄枯草 | 24×28 ～ 36×34；疏草 33×20 |
| 小石子 | `pebbles/pebble_01.png` ～ `pebble_06.png` | 四种单颗石子、两颗组合、三颗组合 | 单颗 8×6 ～ 11×10；组合 21×10、29×11 |

## 像素与落点

- 文件画布统一为 **48×48**。这是透明留边，实际物体大小见 `assets.json` 的 `visible_size`。
- 落地锚点为图片坐标 **(24,44)**，图片中心为 (24,24)。
- `Sprite3D.pixel_size = 0.0234375`，与当前主角一致。中心相对地面上移 **0.46875 米**，即可将底部落点贴到地面。
- 使用固定 Y 轴 billboard、最近邻采样、像素透明裁剪，并接受场景光照。验看场景提供了具体设置。
- PNG 保留原生像素，透明度仅为 0 或 255；处理包括裁切、去除外部背景和补透明边。两颗、三颗石子组合使用原样像素排布，未重画或重采样。
- 已固定导入为无损压缩、关闭 mipmap，关闭自动转为 3D 有损压缩。场景中的透视、景深、灯光与后处理仍会影响屏幕观感。

## Godot 验看

打开 `res://scenes/dressing_preview.tscn` 并按 F6 运行。按 **1 / 2 / 3** 分别查看花、草、小石子。每类六个变种与静态人物比例尺处于同一深度，使用当前四境场景的相机俯角与光影。

主场景 `res://scenes/four_realms.tscn` 已接入铺设，**打开场景的 3D 编辑视图即可看到花草，不需要运行**。按 F5 也可从出生点向右侧草地走查看游戏效果。素材验看场景单独隐藏主地图的铺设，便于比较六个变种。

## 区域内随机铺设

当前使用可编辑的区域框随机生成，默认草密度为 0.28 簇/平方米，花密度为 0.10 簇/平方米，碎石为 0。位置与变种分别随机抽取；相机、景深与素材像素尺度保持现状。道路、土路、水面、桥梁、坡道与台地边缘会自动避让。

## 配置地图上的生成区域

展开主场景 **World / GroundDressing**，下面有两块默认区域：

- **SpawnGrass**：出生点右侧草地。
- **UpperGrass**：右上两岸台地与高层草地。

选中区域节点，在 3D 视图拖动 **X/Z** 位置、水平旋转，或修改 **Area Size** 指定范围。Area Size 的 X 是宽度，Y 是地图 Z 方向的长度，单位为米。编辑器显示蓝色矩形框，游戏中不显示。

- **Enabled**：开关本区域的生成。
- **Categories**：勾选本区域要生成的草、花、碎石。
- **Density Multiplier**：局部密度倍数，0～5；乘以父节点对应类别的密度。
- **本区域资源**：分别勾选草、花、石子的具体变种；每类六种。可让不同区域使用不同素材。父节点“选择资源”也控制允许使用的总资源库，两者取交集。
- 选中一块区域按 **Ctrl+D** 复制，再拖到目标位置，即可新增范围；删除区域即可撤下该范围。区域可以重叠，重叠处可能更密。

## 全局资源、密度与随机种子

选择父节点 **World / GroundDressing**：

- **编辑器预览 / Editor Preview Enabled**：默认开启，不按 F5 就能看到生成的花草；关闭仅隐藏编辑器中的预览，不影响游戏中的铺设。
- **刷新预览**：手动重新生成当前预览；外部脚本热加载后若视图没有更新，可点此按钮。区域和资源配置改变时会自动刷新。
- **铺设密度**：Grass Density、Flower Density、Pebble Density 分别控制每平方米的草丛、花簇、碎石数量，范围 **0～10**。0 隐藏该类。当前密度含义为数量/面积，例如草从 0.28 调到 0.56 会更密，1 或 2 也有效。实际数量会受边缘避让和最小间距限制。
- **选择资源**：多选允许使用的变种，编号对应 PNG 文件的 01～06；具体变种也可在区域节点单独选择。某类全部取消则不生成该类。
- **Scatter Seed**：改变整数，重新随机位置和变种；相同种子与参数可重现相同结果。
- **Minimum Spacing**：落点最小间距，单位为米；越大越疏。达到可用空间容量后，继续提高密度可能无法按目标数量生成。

在编辑器的“**本地 / Local**”场景树调整，改动会直接刷新 3D 视图。**Ctrl+S** 保存主场景，**F5** 使用保存的配置运行。也可以运行时在“远程 / Remote”调整同名节点，但远程改动仅供本次试验，永久配置应在“本地 / Local”保存。

石子当前默认关闭；若之后需要使用，同时提高父节点 Pebble Density 并在目标区域的 Categories 中勾选碎石。

旧的 `data/dressing_layout.json` 与项目根目录 `artifacts/dressing-layout/build_layout.py` 保留为历史铺设记录；当前生成器使用区域节点，不读取旧的固定落点。

## 天气与花草风摆

主场景根节点 **Weather** 是天气总控，默认细雨。配置在本地场景树修改后按 Ctrl+S 保存，运行时也可以在 Remote 中试调。花、草使用带风摆的像素材质，石子保持静止；地编区域、密度和资源选择仍在 GroundDressing 中配置。

| 分组 | 主要参数 | 含义 |
| --- | --- | --- |
| 天气 | Enabled、Weather Mode、Editor Preview | 总开关、晴天/细雨切换、编辑器三维预览 |
| 细雨 | Rain Intensity、Rain Amount | 雨量比例与最大粒子数；提高任一个都会增加雨丝 |
| 细雨 | Rain Speed、Rain Streak Size、Rain Color | 下落速度（米/秒）、雨丝宽长（米）、颜色与透明度 |
| 雨声音效 | Rain Audio Enabled、Rain Sound、Rain Volume Db | 雨声开关、可替换的循环音频、满雨量时音量（分贝） |
| 雨声音效 | Rain Audio Fade Time、Rain Audio Bus | 渐入淡出的时间（秒）、音频总线；只在游戏运行时播放 |
| 花草风摆 | Wind Direction、Wind Strength、Wind Speed | 地图 X/Z 风向、风力与摆动速度；风向也控制雨丝倾斜 |
| 花草风摆 | Gust Strength、Rain Wind Boost | 阵风变化与下雨增加的风力 |
| 花草风摆 | Grass Sway、Flower Sway | 分别控制草叶、花茎顶部摆幅（米），根部不动 |
| 镜头水滴 | Lens Drop Rate、Lens Drop Limit | 满雨量时每秒水滴数、同时存在上限；默认实际约每 2.3 秒一滴 |
| 镜头水滴 | Lens Drop Size | X 为最小半径，Y 为最大半径；像素单位，以 900 像素高画面为基准 |
| 镜头水滴 | Lens Drop Lifetime、Lens Fade Time、Lens Slide Speed | 存续秒数、消失前淡出秒数、向下滑落速度 |
| 镜头水滴 | Lens Blur、Lens Refraction | 仅水滴覆盖区域的轻微模糊与折射；不会给整幅画面增加模糊 |
| 镜头水滴 | Lens Irregularity | 独立轮廓和内部厚度的不规则程度；0 更圆润，1 变化最明显 |
| 镜头水滴 | Lens Light Response | 已有灯光与光晕经水滴产生的局部亮斑强度，保留原光源颜色 |
| 镜头水滴 | Lens Rim Strength | 弧形高光和下侧暗边的强度，帮助辨认透明水滴 |
| 镜头水滴 | Lens Center Protection | 人物附近的水滴保护范围；相对画面高度，0 关闭保护 |
| 水面雨纹 | Water Ripple Density、Size、Strength、Lifetime | 水面涟漪密度、半径、强度、存续时间，可独立开关 |
| 地表雨水 | Ground Splash Density、Size、Strength、Rain Wetness | 地面溅点与额外湿润反馈；草地反馈更轻，原有湿润设置保留 |

三维雨丝和花草风摆可不运行直接预览。镜头水滴在游戏画面中查看，会滑落、淡出并移除；切到晴天后停止新水滴，已有水滴继续自然消失。镜头水滴、雨粒子和生成的风摆材质不作为独立场景节点保存。天气独立于 Camera3D 上的深度景深/椭圆虚化设置。
